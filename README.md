# 🌸 WibuScript
WibuScript adalah bahasa pemrograman esoterik (berbasis TypeScript) yang diciptakan khusus untuk *programmer* tongkrongan yang bosan dengan sintaks bahasa Inggris. 
Bahasa ini menggabungkan slang keseharian dan romaji Jepang, membuat pengalaman *coding* terasa seperti sedang membaca naskah *anime* atau sekadar ngobrol santai.
## ✨ Dua Gaya Penulisan
WibuScript mendukung sistem *Alias*. Kamu bebas memilih gaya penulisan yang panjang (Indo-Jepang) atau versi *shorthand*-nya (Full Romaji) untuk *coding* lebih cepat. Keduanya bisa dicampur secara bebas!

| Konsep Standar | Versi Panjang (Indo-Jepang) | Versi Singkat (Full Romaji) |
| :--- | :--- | :--- |
| `var` / `let` | `koreWa` | `kore` |
| `print()` | `kasihMite()` | `mite()` |
| `if` / `else` | `kaloMoshi` / `chigauDong` | `moshi` / `chigau` |
| `true` / `false` | `majiBener` / `usoBanget` | `maji` / `uso` |
| `loop` / `for` | `ulangZutto` | `zutto` |
| `function` | `bikinJutsu` | `jutsu` |
| `return` | `balikinDesu` | `kaesu` |

## 🚀 Contoh Kode (Versi Singkat)
Sintaks yang bersih, pendek, dan 100% menggunakan romaji keseharian.
```javascript
// Deklarasi variabel
kore statusServer = maji
kore level = 100
// Logika percabangan
moshi (statusServer == maji) {
    mite("Server aman, gas zutto!")
} chigau {
    mite("Server down, uso...")
}
// Bikin fungsi sederhana
jutsu cekKekuatan(power) {
    moshi (power > 90) {
        kaesu maji
    }
    kaesu uso
}
